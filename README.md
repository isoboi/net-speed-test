# net-speed-test

Консольный скрипт на Node.js. Он замеряет скорость скачивания: делает 10 запросов подряд к одному адресу и считает результат.

## Что делает скрипт

1. Принимает адрес (например, ссылку на тяжёлую картинку).
2. Делает к нему 10 запросов **последовательно**. Следующий запрос стартует только после того, как предыдущий ответ скачан полностью.
3. Считает среднее время запроса и общий объём скачанных данных.
4. Печатает скорость скачивания.

## Требования

- Node.js 18 или новее (нужен встроенный `fetch`).
- Зависимостей нет, `npm install` не нужен.

## Запуск

```bash
git clone https://github.com/isoboi/net-speed-test.git
cd net-speed-test
node speedtest.js <адрес>
```

Пример:

```bash
node speedtest.js "https://speed.cloudflare.com/__down?bytes=10000000"
```

Если в адресе есть `?` или `&`, возьмите его в кавычки.

Пример вывода:

```
Скачиваю https://speed.cloudflare.com/__down?bytes=10000000 — 10 запросов подряд

Запрос  1/10: 1330 мс, 10.00 МБ
Запрос  2/10: 1296 мс, 10.00 МБ
...
Запрос 10/10: 1478 мс, 10.00 МБ

Среднее время запроса: 1355 мс
Всего скачано: 100.00 МБ (100000000 байт)
Скорость скачивания: 59.06 Мбит/с (7.38 МБ/с)
```

При ошибке (нет сети, неверный адрес, ответ сервера не 2xx) скрипт печатает причину и завершается с кодом 1.

## Единицы измерения

| Величина | Единица | Значение |
|---|---|---|
| Время запроса | мс | миллисекунды |
| Объём данных | МБ | мегабайт, 1 МБ = 1 000 000 байт |
| Скорость (основная) | Мбит/с | мегабит в секунду, 1 Мбит = 1 000 000 бит |
| Скорость (дополнительно) | МБ/с | мегабайт в секунду, Мбит/с ÷ 8 |

Основная единица — **Мбит/с**: в ней указывают скорость провайдеры и сервисы вроде Speedtest, поэтому результат легко сравнить.

## Как считается результат

- **Время запроса** — от отправки запроса до последнего байта тела ответа.
- **Среднее время** — сумма времени всех запросов ÷ 10.
- **Объём** — сумма размеров тел всех 10 ответов (заголовки не считаются).
- **Скорость** — общий объём ÷ общее время всех запросов.

## Что стоит знать

- Скрипт просит сервер не сжимать ответ (`Accept-Encoding: identity`). Так считаются байты, которые реально прошли по сети.
- Время запроса включает ожидание ответа сервера, а первый запрос — ещё DNS и установку соединения. На маленьком файле эти задержки заметно занижают скорость. Для точного замера берите файл от нескольких мегабайт.
- Результат зависит и от сервера: он может отдавать файл медленнее, чем позволяет ваш канал.

```bash
npm test
```

Тесты поднимают локальный HTTP-сервер и проверяют: запросов ровно 10, они идут по очереди, байты и скорость считаются верно, ошибка сервера даёт понятное сообщение.
